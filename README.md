# 💍 Boda Eric & Laia — 25.09.2026

Lloc web de la boda d'Eric i Laia. Un site estàtic servit amb **GitHub Pages** al domini personalitzat [www.ericilaia.es](https://www.ericilaia.es).

## 📋 Pàgines

| Fitxer | Contingut |
|---|---|
| `index.html` | Pàgina principal amb la data, la ubicació i els horaris (arribada i cerimònia) |
| `la-nostra-historia.html` | Història de la parella amb galeria de fotos |
| `viatge-i-estada.html` | Informació pràctica: com arribar, allotjament i recomanacions |
| `confirmar-assistencia.html` | Formulari de confirmació d'assistència (RSVP) |
| `gracies.html` | Pàgina de confirmació després d'enviar el formulari |

## 🗂 Estructura

```
├── index.html
├── la-nostra-historia.html
├── viatge-i-estada.html
├── confirmar-assistencia.html
├── gracies.html
├── css/
│   └── styles.css
├── assets/            # Imatges de la parella i del lloc
└── CNAME              # Domini personalitzat (www.ericilaia.es)
```

## 🛠 Tecnologies

- **HTML 5** i **CSS 3** — sense frameworks ni dependències externes.
- **GitHub Pages** — hosting estàtic.
- **FormSubmit** — gestió del formulari de confirmació sense backend.

## 🚀 Desplegament

El lloc es desplega automàticament amb GitHub Pages cada cop que es fa push a la branca principal. El domini personalitzat està configurat al fitxer `CNAME`.
